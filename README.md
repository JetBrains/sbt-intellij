# sbt-intellij

> **Project retired.** This historical sbt-to-IntelliJ IDEA project converter is discontinued and retained for reference. No further development or maintenance is planned.
>
> For current sbt projects, use [IntelliJ IDEA with the Scala plugin](https://www.jetbrains.com/help/idea/get-started-with-scala.html) and its [built-in sbt support](https://www.jetbrains.com/help/idea/sbt-support.html).

This project was created as a standalone sbt-to-IDEA project converter for Upsource. It contains declarative sbt and IDEA project models and conversion components.
